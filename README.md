# 纯浏览器移动标牌遮罩光流跟踪台

无服务器、无上传：媒体写入 OPFS，遮罩工程写入 IndexedDB；页面关闭后源文件仍只保存在浏览器本地存储中，导出的是遮罩元数据，不会覆盖原视频。

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

建议使用最新桌面版 Chrome / Edge / Chromium，并通过 http(s) 打开。页面会先检测 WebCodecs、H.264、WebAssembly、OPFS、IndexedDB；能力缺失时直接给出明确提示，不会进入不可用流程。

## 格式与限制

- 限定容器：MP4。
- 限定编码：H.264 / AVC（`avc1` / `avc3`），非 AVC 文件会拒绝并提示实际编码。
- 运动模型：二维仿射（OpenCV.js `estimateAffine2D` + RANSAC）。
- 遮罩形状：二维多边形，顶点坐标为“旋转与像素比例校正后的显示归一化坐标”。
- 不做三维透视、深度遮挡推断或无人工依据的长距离插值。

页面内三个“自制样本”由 Canvas + `VideoEncoder` 现场编码成 H.264 MP4：

1. 清晰移动：标牌平移并轻微旋转；带明确的 90° 显示旋转与 3:4 PAR 覆盖。
2. 运动模糊：中段强烈运动模糊，应触发置信下降暂停。
3. 短暂出画：标牌离开画面后返回，出画阶段应暂停并等待人工关键帧。

## 操作流程

1. 导入 MP4/H.264，或生成自制样本。
2. 如需纠正容器元数据，在导入前明确设置旋转和 PAR。
3. 拖到起始时间，点击“编辑/新增关键帧”，调整黄色多边形，然后“保存人工关键帧”。
4. 点击“从最近人工关键帧跟踪到末尾”。
5. 若光流不一致、模糊、出画、仿射矩阵异常或综合置信度低，时间轴产生黄色缺口并暂停；系统不会在缺口处显示猜测遮罩。
6. 在暂停位置人工调整并保存新的关键帧，再继续。
7. 保存工程到 IndexedDB，或导出 JSON 遮罩元数据。

## 时间戳约定

内部播放、跟踪、关键帧和导出都使用实际秒数：

```text
WebCodecs VideoFrame.timestamp / 1_000_000  // 容器 PTS，秒
```

不会把数组下标当作时间。解码帧按 DTS 送入解码器，输出按 PTS 排序；B 帧重排时仍以 `VideoFrame.timestamp` 定位。

## 防漂移判定

OpenCV.js 对每一对相邻解码帧执行：

- FAST 角点 + 多边形内确定性网格/边缘种子；
- Lucas–Kanade 前向光流；
- Lucas–Kanade 反向一致性检查；
- RANSAC 二维仿射拟合；
- 单帧缩放、翻转、旋转、平移和候选面积异常检查；
- 当前候选区域 Laplacian 锐度估计；
- 综合内点比例、跟点率、反向误差、出画面面积和锐度计算置信度。

任一硬性条件失败或置信度低于阈值都会暂停。黄色缺口不会被自动补齐，也不会在导出元数据中宣称该时间段已有有效遮罩。

## 导出 JSON

导出文件包含：

- 源文件名称、大小、媒体 ID、SHA-256；
- 解码尺寸、旋转、PAR；
- PTS 秒时间基；
- 人工关键帧；
- 已验证光流轨迹及置信度；
- 人工等待缺口及原因。

JSON 可由外部播放器或后续工具按 PTS 秒重放；缺口必须通过人工关键帧或另行处理来闭合。
